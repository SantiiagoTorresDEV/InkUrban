# InkUrban

InkUrban is a desktop application developed in Java for a university project focused on Object-Oriented Programming.

The application represents a graffiti products store and includes two different views: one for administrators and another for customers. It was built to apply the concepts learned during the course while creating a functional desktop application.

## Features

- User login
- Administrator and customer roles
- Product management
- Shopping cart
- Sales registration
- Invoice generation
- Default products available during execution

## Technologies

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- UML
- Visual Studio Code

## About the Project

This project was developed to practice object-oriented programming by building a desktop application from start to finish.

One of the biggest challenges was designing the shopping cart so that each user had their own cart during the execution of the program. Solving that problem helped me better understand how to organize classes and manage objects within an application.

The project also gave me practical experience working with Java Swing and UML diagrams.

## Current Limitations

The application does not use a database yet.

All users, products and sales exist only while the program is running, so the information is not saved after closing the application.
